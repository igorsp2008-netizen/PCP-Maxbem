# MAXBEM PCP para Mac Apple Silicon — avaliação

Baixe `MAXBEM_PCP_Mac_v1.7.0_Apple_Silicon.zip`, extraia todo o ZIP e abra `MAXBEM_PCP_Mac/MAXBEM PCP.app`.

Requer macOS 14 ou posterior em Apple Silicon, incluindo M5. O runtime está incluído; não precisa instalar Node.js, Python ou PowerShell. Para encerrar, abra `Encerrar_MAXBEM_PCP.command`.

O pacote não tem assinatura/notarização Apple. Consulte `LEIA-ME.txt` dentro do ZIP para abertura e cuidados com backups. Servidor e interface passaram por testes em Linux; Finder, Safari e execução nativa no macOS ainda precisam ser avaliados. Use cópia dos dados.

O arquivo `.sha256` permite conferir a integridade do ZIP.

## Windows 10/11 — versão 1.7.0

Baixe `MAXBEM_PCP_Windows_v1.7.0_Seguranca_e_Confiabilidade.zip`, extraia todo o ZIP e execute `MAXBEM_PCP_Windows/INSTALAR_MAXBEM_PCP.bat` sem privilégios administrativos. Depois, abra o atalho MAXBEM PCP na Área de Trabalho.

Antes de atualizar, exporte um backup externo e feche o aplicativo e o servidor antigo. O pacote inclui `LEIA-ME.txt` e relatório de segurança. Servidor e interface foram testados em Linux com PowerShell e Chromium; instalação, atalhos e execução no Windows ainda precisam de validação. O pacote não tem assinatura digital.
